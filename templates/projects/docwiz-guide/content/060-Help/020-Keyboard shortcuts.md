# Keyboard shortcuts

The keys worth learning, by where you use them. For a printable version, open the [quick reference card](../../attachments/quick-reference.pdf).

## Writing {#writing}

{#keys-writing widths="40% 60%"}
| Keys | What they do |
|------|--------------|
| Ctrl+Z | Undo — page and sidebar changes, newest first |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+S | Save now (DocWiz also saves by itself) |
| Ctrl+B / Ctrl+I | Bold / italic |
| Ctrl+V | Paste — a picture is stored in the project for you |
| Tab / Shift+Tab | In a list: move the item in / out a level |
| Enter on an empty last line of a block | Leave the block |
| Delete | Delete the selected picture, table or block |
| Esc | Leave the selected picture, table or block; close a menu |
| / at the start of a line (on slides and in documents) | Quick insert menu |

## Tables {#tables}

{#keys-tables widths="40% 60%"}
| Keys | What they do |
|------|--------------|
| Tab / Shift+Tab | Next / previous cell |
| Enter | Finish the cell |
| Shift+Enter | New line inside the cell |
| Esc | Leave the cell without keeping what you typed |

## Menus and dialogs {#menus}

{#keys-menus widths="40% 60%"}
| Keys | What they do |
|------|--------------|
| ↑ / ↓ | Move through a menu |
| Enter or Space | Choose the highlighted item |
| Esc | Close the menu or dialog |
| Enter (while renaming in the sidebar) | Keep the new name |

## Zoom {#zoom}

In the editor and in the handover, these zoom the page's content between 50% and 300%; the bars and menus stay the same size.

{#keys-zoom widths="40% 60%"}
| Keys | What they do |
|------|--------------|
| Ctrl+mouse wheel | Zoom in or out |
| Ctrl+plus / Ctrl+minus | Zoom in / out |
| Ctrl+0 | Back to 100% |

## Presenting {#presenting}

{#keys-presenting widths="40% 60%"}
| Keys | What they do |
|------|--------------|
| → , Page Down or Space | Next slide |
| ← or Page Up | Previous slide |
| F | Full screen on or off |
| Esc | Leave full screen |
