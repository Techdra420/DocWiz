# Glossary

The words this guide uses, in alphabetical order.

{#glossary-table widths="24% 76%"}
| Word | Meaning |
|------|---------|
| Attachment | A document handed over as it is — a PDF data sheet, a certificate. Shown in the handover's **Attachments** tab. See [Links and attachments](dw:links#attachments). |
| Audience | A group of readers, such as *Author* or *Administrator*. Each output is made for one. See [Readers and audiences](dw:readers). |
| Building block | A ready-made element: a callout, procedure steps, cards, buttons, a collapsible section. See [Building blocks](dw:building-blocks). |
| Callout | A note, tip, warning or danger box. |
| Chapter | One page of the manual, with one title. Chapters are grouped into sections. |
| Check | Looks through the whole project for broken links, missing pictures and other problems. See [Check messages](dw:check-messages). |
| Context bar | The bar under the toolbar with the tools for the selected picture, table or block. |
| Document | An output for reading: one page of sections for one audience. See [Documents](dw:documents). |
| Documentation package | A ready-made website, such as an API reference, shipped in its own tab of the handover. See [Documentation packages](dw:documentation-packages). |
| Group | A named set of blocks in a chapter, made so that a slide or document can show exactly those blocks. |
| Handover | The folder of web pages DocWiz builds for readers: the manual, the outputs, the attachments and the packages. See [Building the handover](dw:handover). |
| History | Every saved version of every chapter and output, kept in the project. See [Saving, undo and history](dw:history). |
| Linked section | A part of a chapter shown on a slide or in a document, kept in sync with the chapter. |
| Link ID | A chapter's permanent name for links. It never changes, even when the chapter is renamed. |
| Manual | All chapters in order — the one source of truth everything else is built from. |
| Named version | A snapshot of the whole project under a name, such as *Handover 1.0*. |
| Output | A slide deck or a document, made from the manual for one audience. |
| Preview as | Shows the manual as one audience will get it. |
| Readers | Who a chapter, paragraph or step is for. |
| Section | A group of chapters, shown as a heading in the sidebar. |
| Slide deck | An output for presenting. See [Slide decks](dw:slide-decks). |
| Source | The plain text behind a chapter, for the rare occasion you need it. |
| Template | A project used as the starting point for new ones. See [Project templates](dw:templates). |
