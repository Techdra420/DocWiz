# Troubleshooting

## Common problems {#common-problems}

| Symptom | Likely cause | Action |
|---------|--------------|--------|
| Cannot sign in | Wrong password or locked account | Reset the password |
| Page loads slowly | Server under load | Check the server status page |
| Report is empty | Filter too narrow | Widen the date range |

## Getting help {#getting-help}

Who to contact and what to include in a support request: the screen, the time, and
the error message.

::: audience admin
Log locations, diagnostic commands, escalation path.
:::
